# AI-Powered Resume Builder

ဤပရောဂျက်သည် အလုပ်အကိုင်ရှာဖွေနေသော ကျောင်းသားများနှင့် လူငယ်များအတွက် အလုပ်ခေါ်စာ (Job Description) နှင့် ကိုက်ညီသော Resume များကို AI နည်းပညာဖြင့် အလိုအလျောက် ပိုမိုကောင်းမွန်အောင် ပြုပြင်ပေးသည့် စနစ်တစ်ခု ဖြစ်ပါသည်။

## 🚀 Key Features
- **Smart Optimization:** Job Description နှင့် ကိုက်ညီအောင် AI (Llama 3) ဖြင့် အလိုအလျောက် ပြင်ဆင်ပေးခြင်း။
- **Template Selection:** ကိုယ်ပိုင်ဟန်ဖြင့် ရွေးချယ်နိုင်သော Resume Template များ (Minimal, Modern, Creative)။
- **Format Flexibility:** PDF နှင့် DOCX ဖိုင်ပုံစံဖြင့် Download ရယူနိုင်ခြင်း။
- **User-Centric Design:** အသုံးပြုရလွယ်ကူပြီး အချိန်ကုန်သက်သာစေသော UI/UX။

## 🛠 Tech Stack
- **Frontend:** Next.js, Tailwind CSS, TypeScript
- **Backend:** FastAPI, Python
- **AI Integration:** Groq API (Llama-3 model)
- **PDF Generation:** jsPDF

## 📦 Installation & Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/myazarcho/ai-resume-builder.git
   ```
2. Setup Backend:
   ```bash
   cd backend
   pip install -r requirements.txt
   uvicorn main:app --reload
   ```
3. Setup Frontend:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

## 💡 Why this project?
ဤပရောဂျက်သည် user များအတွက် အချိန်ကုန်သက်သာစေရန်နှင့် အလုပ်လျှောက်ထားရာတွင် အောင်မြင်မှုနှုန်း ပိုမိုမြင့်မားစေရန် ရည်ရွယ်၍ တီထွင်ထားပါသည်။
